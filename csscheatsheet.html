1. Selectors

Selectors choose which HTML elements to style.

  • p element selector
  • .class class selector
  • #id ID selector
  • * universal selector
  • div p descendant selector
  • div > p child selector
  • h1, h2 grouping (same styles for both)
  • h1 + p adjacent sibling
  • h1 ~ p general sibling
  • a[href] attribute selector

Pseudo-classes (a state or position)

:hover:active:focus:focus-within:visited:first-child:last-child:nth-child():not()

Pseudo-elements (a part of an element)

::before::after::first-line::placeholder

::before and ::after only appear when the content property is set.

.note::before {
  content: "Note: ";
  font-weight: bold;
}

2. Specificity and the Cascade

When two rules clash, the more specific selector wins. From strongest to weakest:

  1. Inline styles
  2. ID selectors
  3. Class, attribute and pseudo-class selectors
  4. Element selectors

If specificity is equal, the rule written last wins. !important overrides everything, so avoid it.

5. The Box Model

Every element is a box made of content, padding, border and margin.

margin: 10px;
padding: 10px;
border: 1px solid black;
box-sizing: border-box;

Properties

marginpaddingborderwidthheightmin-widthmax-widthmin-heightmax-height

box-sizing

  • content-box default: padding and border are added to the width
  • border-box padding and border are included in the width

Shorthand

margin: 10px 20px;
margin: 10px 20px 30px 40px;

One value sets all sides, two values set top/bottom then left/right, and four values go clockwise from the top.

Size values

autofit-contentmin-contentmax-content

6. Display

Determines how an element behaves in the layout.

display: block;
blockinlineinline-blockflexinline-flexgridinline-gridnone

none removes the element from the layout.

7. Position

Controls element placement.

position: relative;
top: 10px;

Position values

  • static default
  • relative offset from its normal spot
  • absolute placed against the nearest positioned ancestor
  • fixed placed against the viewport
  • sticky scrolls, then sticks

Related properties

toprightbottomleftinsetz-index

inset is shorthand for all four sides.

17. Custom Properties and Functions

:root {
  --main-color: teal;
}

p {
  color: var(--main-color);
  width: calc(100% - 20px);
}
  • --name defines a custom property
  • var() uses a custom property
  • calc() does maths with mixed units

18. Media Queries

Apply styles only when a condition is true, such as a small screen.

@media (max-width: 768px) {
  .menu {
    display: none;
  }
}
  • @media starts a media query
  • max-width applies at this width and below
  • min-width applies at this width and above
  • orientation accepts portrait or landscape

20. Global Values

These work on any property.

  • inherit take the parent’s value
  • initial use the CSS default
  • unset inherit if possible, otherwise initial
  • revert go back to the browser’s default style
